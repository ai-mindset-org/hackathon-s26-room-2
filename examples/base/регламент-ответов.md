# Регламент ответов клиентам

1. Обращение по имени, на «вы», без канцелярита.
2. В ответе на проблему: сначала шаги решения, потом причина, в конце — что
   делать, если не помогло (контакт поддержки).
3. Цены называем только из действующего прайса, со ссылкой на артикул.
4. Сроков «завтра» не обещаем — только сроки из прайса.
5. Если ответа в базе нет — честно говорим и передаём менеджеру. Выдумывать нельзя.
6. Подпись: «Команда ТехноСклад».
